# Syncthing

## Роли папок

| Папка | Телефон | Сервер | Назначение |
| --- | --- | --- | --- |
| `Recordings` / `audio_in` | Send Only | Receive Only | аудио с телефона на сервер |
| `Transcripts` / `audio_out` | Receive Only | Send Only | готовые `.md` с сервера на телефон |

## Почему серверный `audio_in` receive-only

Телефон является источником аудио. Сервер должен только принимать записи, а не менять их. Worker копирует файлы из `audio_in` в локальную очередь и обрабатывает копии.

Если сервер удаляет или меняет файлы в receive-only папке, Syncthing может показать override/revert состояние. Поэтому этот проект не удаляет исходники из `audio_in`.

## Как чистить старые аудио

Лучший вариант: удалять старые записи на телефоне после проверки, что расшифровка уже пришла. Удаление синхронизируется на сервер.

Если хочется серверную чистку, делайте её только вне Syncthing-папок, например в `~/.local/share/recognition/jobs`. Не удаляйте `~/sync/audio_in` автоматикой без понимания последствий.

## Доступ к UI

Не открывайте порт `8384` в публичный интернет. Используйте SSH tunnel:

```bash
ssh -L 8384:127.0.0.1:8384 user@server
```

Затем:

```text
http://127.0.0.1:8384
```
